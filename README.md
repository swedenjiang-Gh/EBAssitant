# EBAssistant

使用 C# 和 Windows Forms 开发的 Engineering Base 辅助工具。

## 当前功能

主界面提供以下入口：

- 属性
- 类型定义
- 工作表
- 权限配置
- 图形模板
- 工具面板配置

“属性”入口已支持连接当前活动的 EB 2023/2024，读取数据库属性分类目录，
刷新及新建属性目录，并从 Excel 批量创建属性。属性类型映射可在导入界面中查看和配置。
EB 2025 适配器将在本机注册 COM 32 类型库后启用。

“类型定义”入口支持缓存类型定义树、父子复选联动，并通过 Excel 批量将属性 ID
添加到叶级类型对象的定义对话框选项卡。操作结果会保存到本地日志目录。

“工作表”入口支持缓存项目模板树。只有点击“刷新”才重新读取 EB；在模板项目上右键
“新建工作表”可从 Excel 批量创建器件工作表，并保存到所选项目的
`工作表 / 收藏夹`。每次操作都会显示结果并保存日志到
`%LOCALAPPDATA%\EBAssistant\Logs\Worksheets`。

属性 Excel 首个工作表的首行为标题，从第二行开始读取：

- 第二列：属性名称
- 第三列：属性类型

工作表 Excel 规则：

- 每个 Excel 页签对应一个 EB 工作表。
- 第一列忽略。
- 从第二列开始，第一行是列标签预览，第二行是属性 ID。
- 列标签用于预览、列宽计算和日志，不写入 EB；EB 显示默认属性名称。

## 运行

```powershell

```
