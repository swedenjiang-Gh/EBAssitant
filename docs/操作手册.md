# EBAssistant 操作手册

## 安装时检查运行环境

- 使用 `EBAssistant-<版本>-x86-Setup.exe` 安装，先查看当前电脑的 .NET Framework 版本；程序最低要求为 4.6.2。
- 已安装 4.6.2 或更高版本时，直接继续安装 EBAssistant，保留现有 Framework。
- 低于最低要求时，勾选同意运行微软 .NET Framework 4.6.2 离线安装程序，先补装 4.6.2 再安装 EBAssistant。未同意安装时不能进入下一步。
- 选中运行环境安装后，会打开微软安装窗口供用户确认许可条款。需要重启时先保存其他工作，再按提示处理。
- 安装失败页面提供日志入口。卸载 EBAssistant 不会卸载系统共享的 .NET Framework。
- 单独运行 MSI 不补装运行环境，缺少最低版本时会停止安装并提示使用 Setup.exe。

本文面向日常使用者，说明如何启动 EBAssistant，以及如何使用六个功能入口。涉及 EB 写入的功能都应先检查预览和确认弹窗，再执行。

## 1. 启动前准备

1. 打开 Engineering Base，并连接目标数据库。
2. 确认要操作的是当前活动 EB 实例。多个 EB 版本同时运行时，部分窗口会弹出版本选择框。
3. 如需重新构建程序，先在项目根目录执行：

```powershell
.\build.ps1
```

4. 启动程序：

```powershell
.\bin\Debug\net10.0-windows\EBAssistant.exe
```

也可以使用：

```powershell
dotnet run --project .\EBAssistant.csproj
```

## 2. 主界面

主界面提供六个功能入口：

- 属性
- 类型定义
- 工作表
- 权限配置
- 图形模板
- 工具面板配置

菜单功能：

- 文件 / 下载模板：把 `Templates/` 下的 Excel 模板复制到指定目录。
- 辅助工具 / 属性ID匹配、VISIO图形组合：当前为占位入口，点击后提示后续开发，尚不执行实际处理。
- 日志：打开 `%LOCALAPPDATA%\EBAssistant\Logs`。
- 关于 / 帮助：打开内置 `docs/操作手册.md`。
- 关于 / 版本信息：显示内置 `CHANGELOG.md`。

版本说明：

- 主界面标题会显示当前程序版本号。
- 开发过程中的多次修改可以累计；提交代码前统一决定版本号，并同步更新 `CHANGELOG.md` 和本操作手册。
- 版本号使用三段格式，例如 `V1.1.0`。

## 3. 属性

用途：读取 EB 属性目录，并从 Excel 批量创建属性。

操作步骤：

1. 点击“属性”。
2. 程序连接当前活动 EB，读取或加载缓存的属性目录树。
   - 完整读取通过一次遍历同时获取目录树和已有属性名称，最多等待 60 秒；导入时使用名称列表检查重名，创建前仍会实时复核。
3. 如需强制重新读取 EB，点击“刷新”。
4. 在目标属性目录上右键：
   - “新建目录”：在所选目录下创建用户属性目录。
   - “创建属性”：打开 Excel 批量创建窗口。
5. 在“创建属性”窗口导入 Excel，检查只读预览和校验结果。
6. 确认无错误后执行创建。
7. 操作结束后查看结果窗口，并通过日志目录按钮查看 JSON/TXT 日志。

属性 Excel 规则：

- 支持 `.xlsx` 和 `.xls`。
- 读取首个工作表。
- 第一行为标题。
- 从第二行开始读取。
- 第二列为属性名称。
- 第三列为属性类型。
- 第四列为属性注释，可为空。
- 名称和类型都为空的行会被忽略。

注意：

- 表格内重名、EB 中已有同名、类型无法映射、名称为空、类型为空都会阻止确认。
- EB 2023 适配器不支持公式属性类型。
- 批量创建中途失败时，本批已创建属性会尽力回滚。

## 4. 类型定义

用途：把属性 ID 批量添加到类型定义对话框选项卡。

操作步骤：

1. 点击“类型定义”。
2. 程序连接当前活动 EB，读取或加载缓存的类型定义树。
3. 勾选目标目录或叶级类型对象。勾选父节点会递归勾选子节点。
4. 点击“定义对话框”。
5. 导入 Excel，检查预览和 AID 校验结果。
6. 确认后执行写入。
7. 在结果窗口查看 `added`、`skipped_existing`、`failed` 状态，并打开日志目录。

类型定义 Excel 规则：

- 支持 `.xlsx` 和 `.xls`。
- 读取首个工作表。
- 第一行为标题。
- 从第二行开始读取。
- 第二列为选项卡名称。
- 第三列为正整数属性 ID。
- “选项卡名称 + AID”重复行会合并。

注意：

- 实际写入只作用于可操作的叶级 TypeItem，并按 ID 去重。
- 已存在 AID 会跳过，不调整原有选项卡。
- 任一写入失败时停止后续操作；此前成功的写入保留。

## 5. 工作表

用途：从 Excel 批量创建器件工作表，并保存到所选模板项目的收藏夹。

操作步骤：

1. 点击“工作表”。
2. 程序连接当前活动 EB，读取或加载缓存的项目模板树。
3. 如需重新读取 EB，点击“刷新”。
4. 在模板项目节点上右键，选择“新建工作表”。
5. 导入工作表 Excel，检查只读预览、列校验和 EB AID 校验。
6. 确认后执行创建。
7. 结果窗口会显示每个页签的创建状态、保存路径和日志目录。

工作表 Excel 规则：

- 每个 Excel 页签对应一个 EB 工作表。
- Excel 页签名称作为工作表名称来源。
- 第一列忽略。
- 从第二列开始：
  - 第一行是列标签。
  - 第二行是属性 ID。
- 空列会忽略。

注意：

- EB2023 下会将第一行写入工作表列标签，写入后按内部列记录读回确认。
- 列标签写入使用受控 SQL 内部列记录路线；EB2024 当前不开放该写入路径。
- 工作表对象类型当前固定为器件。
- 单个工作表失败后继续处理其他有效工作表。
- 保存位置为所选项目自己的 `工作表 / 收藏夹`，不跨项目创建后移动。

## 6. 权限配置

用途：把用户或用户组添加到权限控制目录。

操作步骤：

1. 点击“权限配置”。
2. 程序连接当前活动 EB，读取或加载缓存的权限配置结构。
3. 左侧选择用户或用户组。
4. 右侧选择权限控制目录。
5. 点击“应用权限配置”。
6. 在确认窗口核对用户、目录和组合数量。
7. 确认添加后查看结果窗口和日志。

注意：

- 当前只添加权限成员，不设置具体权限位。
- 已存在的用户或用户组会跳过。
- 操作结果包含新增、跳过和失败数量。

## 7. 图形模板

用途：读取图形模板目录，复制模板图形，或按已有模板补齐同目录内模板数量。

操作步骤：

1. 点击“图形模板”。
2. 程序连接当前活动 EB，读取或加载缓存的图形模板目录。
3. 如需重新读取 EB，点击“刷新”。
4. 选择源模板图形和目标目录后，可以执行：
   - “迁移模板图形”：把选中的模板图形复制到目标末级目录。
   - “新建模板图形”：当所选末级目录中恰好只有一个模板图形时，以它为源复制到指定总数量。
   - “按表格迁移”：导入 Excel 并生成预览；当前不执行写入。
   - “Visio批量创建”：选择的目录下有且只能有一个模板图形，复制这个模板图形粘贴到该目录下形成新的模板图形，打开新的模板图形后，从选择visio文件，按从上到下从左到右的顺序复制组合图形粘贴到打开的新的模板图形后关闭并保存。
5. 操作结束后查看结果窗口和日志。

注意：

- 迁移模板图形是复制，不删除源模板。
- 目标必须是最后一级图形模板目录。
- “新建模板图形”的请求总数量必须至少为 2，最多为 200。
- 部分 EB 交互确认框由适配器自动处理；失败时以日志为准。
- 首次没有缓存时完整读取图形模板，状态栏显示目录数、模板数、耗时和当前阶段；成功后保存缓存，再次打开直接复用。完整读取最多等待 180 秒，单目录刷新最多等待 60 秒。
- 读取诊断日志位于 `%LOCALAPPDATA%\EBAssistant\Logs\Diagnostics\GraphicTemplateReads`，可从主界面“日志”入口进入。超时提示包含最后进度和具体日志路径；超时本身不代表管理员权限不一致。

## 8. 工具面板配置

用途：把图形模板关联到已有工具面板条目。

操作步骤：

1. 点击“工具面板配置”。
2. 程序加载图形模板目录和工具面板配置目录。
3. 左侧选择图形模板目录，中间选择一个或多个模板图形。
4. 右侧选择目标工具面板配置条目。
5. 点击“添加到工具面板”。
6. 在确认弹窗中核对模板数量和目标路径。
7. 确认后查看结果窗口和日志。

注意：

- 目标必须是已有 Kind 415 工具面板条目。
- 该操作建立模板图形引用，不复制、不迁移、不新建 Kind 415 条目。
- 写入后可能需要重启 EB 才能看到工具面板变化。

## 9. 缓存与日志

缓存目录：

```text
%LOCALAPPDATA%\EBAssistant\Cache
```

日志目录：

```text
%LOCALAPPDATA%\EBAssistant\Logs
```

各功能日志子目录：

- `Attributes`
- `TypeDefinitions`
- `Worksheets`
- `PermissionConfiguration`
- `GraphicTemplates`
- `ToolPanelConfiguration`

缓存只在用户点击刷新或缓存协议变化时重新生成。排查数据不一致时，优先在对应窗口点击“刷新”。

## 10. 常见问题

未检测到活动 EB：

- 先打开 Engineering Base。
- 确认 EB 已连接数据库。
- 确认 Engineering Base 和 EBAssistant 使用同一 Windows 用户、同一权限级别运行；例如 EB 以管理员身份运行时，EBAssistant 也要以管理员身份运行。
- 查看提示中的诊断信息和诊断日志路径；日志默认保存在 `%LOCALAPPDATA%\EBAssistant\Logs\Diagnostics`。
- 检查安装目录下是否存在对应版本适配器，例如 `Adapters\2024\EBAssistant.Adapter2024.exe` 和同目录的 `Interop.Aucotec.dll`。
- 重新打开对应功能窗口。

找不到适配器：

- 先执行 `.\build.ps1`。
- 检查 `bin\Debug\net10.0-windows\Adapters\2023` 和 `Adapters\2024` 下是否存在适配器 EXE。

Excel 导入后不能确认：

- 查看预览表格中的校验信息。
- 修正空名称、空类型、重复项、非法 AID 或 EB 中不存在的 AID。

看不到最新 EB 目录：

- 点击当前窗口的“刷新”。
- 如果仍旧不一致，关闭窗口后重新打开。

EB 2025 不可用：

- 当前 EB 2025 适配器只是占位程序，不支持实际连接。
