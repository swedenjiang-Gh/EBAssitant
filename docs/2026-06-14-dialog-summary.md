# 2026-06-14 项目阶段复盘

本文按当前代码状态整理 EBAssistant 的阶段性结果、保留下来的经验和已经排除的半路方案。旧复盘里出现过的测试组数、占位入口和临时授权方案，均以本文和当前代码为准重新校准。

## 当前结果

EBAssistant 当前六个主功能入口均已接入实际窗口：

- 属性
- 类型定义
- 工作表
- 权限配置
- 图形模板
- 工具面板配置

主程序保持 WinForms + `net10.0-windows` + x86。EB 2023/2024 适配器保持 `.NET Framework 4.6.2` + x86 + 强类型 Aucotec COM Reference。EB 2025 适配器仍是明确报错的占位程序。

主程序仍只负责界面、Excel 导入、预览、缓存、日志和 adapter 调用；EB COM、UI Automation、数据库关联等高风险细节都收敛在版本化适配器中。

## 已完成的关键能力

### 属性

- 读取并缓存用户属性目录。
- 支持刷新目录。
- 支持新建属性目录。
- 支持从 Excel 批量创建属性。
- 支持属性类型映射配置。
- 批量创建前做预校验，写入后读回确认。
- 中途失败时停止，并尽力删除本批已创建属性。
- 保存 JSON/TXT 操作日志。

### 类型定义

- 读取并缓存类型定义树。
- 支持复选联动和末级 TypeItem 去重。
- 支持从 Excel 批量把 AID 添加到类型定义对话框选项卡。
- 已存在 AID 跳过，不调整原有选项卡。
- 写入失败时停止后续操作，已成功写入保留。
- 保存 JSON/TXT 操作日志。

### 工作表

- 读取并缓存项目模板树。
- 模板项目右键新建工作表。
- Excel 多页签批量创建器件工作表。
- 每个页签对应一个工作表，第一列忽略，第二列开始为工作表列。
- 第一行标签仅用于预览、列宽计算和日志；第二行为属性 ID。
- 使用所选项目自己的 `EquipmentFolder.OpenWorksheetDirect(...)` 创建，再保存到同一项目的 `工作表 / 收藏夹`。
- 单个工作表失败后继续处理其他有效工作表。
- 保存 JSON/TXT 操作日志并展示结果。

### 权限配置

- 读取并缓存用户、用户组和权限控制目录结构。
- 支持把选中的用户或用户组添加到选中的权限目录。
- 当前只添加成员，不设置具体权限位。
- 执行前展示预览，执行后读回确认并记录 `added`、`skipped_existing`、`failed`。
- 保存 JSON/TXT 操作日志。

### 图形模板

- 读取并缓存图形模板目录和模板图形。
- 刷新只浅层刷新当前目录。
- 支持复制选中的模板图形到目标末级目录，源对象保留。
- 支持基于当前目录唯一模板补齐创建多个模板图形。
- 支持导入“按表格迁移”Excel 做只读预览；当前不执行批量迁移写入。
- 只自动处理已白名单化的 EB 类型不匹配确认框。
- 保存 JSON/TXT 操作日志。

### 工具面板配置

- 复用图形模板缓存。
- 读取并缓存 `数据库 / 模板 / 工具面板配置` 下的目录和 `Kind 413 / 414 / 415` 条目。
- 支持把选中的模板图形关联到已有 `Kind 415` 工具面板条目。
- 不复制模板图形，不新建 `Kind 415`，不删除已有面板。
- 当前实现依据是 `Kind 415` 通过 `Role 132` 指向真实图形模板对象。
- 写入后读回确认，并提示重启 EB。
- 保存 JSON/TXT 操作日志。

## 保留的经验

1. adapter 协议必须两边同步。
   - `EbAdapterClient` operation 名称、主程序模型、adapter DataContract 模型必须同时更新。
   - operation 名称大小写和拼写要完全一致。
   - 新增请求或响应字段时，不能只改主程序或只改 adapter。

2. 缓存只用于展示，写入前必须重新解析目标。
   - 目录树缓存要按 EB 版本和根目录 ID 隔离。
   - 用户刷新时才重新读取。
   - 执行写入前必须通过 adapter 用 ID 重新解析对象。

3. 写入必须有“预览、确认、执行、读回、日志”闭环。
   - 属性、类型定义、工作表、权限、图形模板、工具面板配置都遵守这个方向。
   - API 没有抛异常不等于 EB 已经稳定可见。
   - 对 EB 延迟可见的对象，应使用读回或轮询确认。

4. 失败策略要按功能边界写清楚。
   - 属性创建失败会尽力回滚本批已创建属性。
   - 类型定义写入失败后停止，已成功的保留。
   - 工作表按页签继续处理。
   - 图形模板复制或新建已成功对象保留，不做自动批量删除。
   - 工具面板和权限配置逐项记录成功、跳过或失败。

5. 主程序不要碰 EB COM。
   - 主程序不引用 Aucotec COM。
   - 不使用 `dynamic`。
   - EB 2023/2024 真实调用留在 x86 adapter。

6. 本地授权方案已最终移除。
   - 旧复盘里提到过隐藏入口、密码框、机器码、`.ealic` 等方案。
   - 当前代码不做授权校验，主功能按钮不因授权状态禁用。
   - 后续不要恢复相关入口，除非重新设计完整授权策略，并明确它只能提高门槛。

7. 项目资源随输出目录管理。
   - Excel 模板放在 `Templates/`，帮助文档使用 `docs/操作手册.md`，版本更新日志放在根目录 `CHANGELOG.md`。
   - `.csproj` 负责复制到输出目录。
   - “下载模板”扫描输出目录中所有 Excel 文件，不维护硬编码清单。

## 已排除或不能默认使用的路线

- 工作表自定义列标签在当时暂未实现；后续已升级为 EB2023 受控 SQL 内部列记录写入。
- `aucCmdEditColumnLabel` 不是稳定的纯 COM 写入接口。
- SQL 内部表修改只能作为人工明确批准的受控诊断修复路线，不能作为产品默认功能。
- 图形模板跨大类复制不视为已支持能力。
- “按表格迁移”图形模板当前只做预览，不做写入。
- 工具面板配置不是图形模板迁移，不能复用复制/粘贴逻辑。
- 工具面板配置当前不自动新建 `Kind 415` 条目。
- 权限配置当前不设置具体权限位。
- EB 2025 当前不支持真实连接。

## 后续维护注意

1. 新增功能前先查 `../EngineeringBaseCodemap` 的 confirmed 证据。
2. 只把 confirmed 或明确版本适用的结论当作实现依据。
3. 真实 EB 写入验证只能在受控数据库中执行，不要在用户生产数据库中试写。
4. 每次写入功能完成后都应有结果窗口和日志目录入口。
5. 修改缓存结构时提升对应 `ProtocolVersion`。
6. 修改 adapter 请求/响应时同步 `Models.cs` 和 `Adapters/AdapterProgram.cs` 底部 DataContract 模型。
7. 如果 `EBAssistant.exe` 或 adapter EXE 正在运行，构建可能被文件锁阻塞；验证前先关闭当前程序和卡住的 adapter。
