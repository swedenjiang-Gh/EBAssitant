# 图形模板按表格迁移与新建设计

## 目标

在现有“图形模板”窗口新增两个入口：

- “按表格迁移”：导入迁移表格并基于当前缓存只读预览，点击“确定”后的实际迁移功能暂不开发。
- “新建模板图形”：在满足目录条件时，通过复制目录中唯一的模板图形，创建指定总数量的模板图形。

## 按表格迁移

### 界面

- 在“图形模板”窗口工具栏新增“按表格迁移”按钮。
- 点击后打开独立非模态窗口。
- 窗口包含：
  - “导入表格”按钮
  - 只读预览表格
  - 导入结果摘要
  - “确定”按钮
- 点击“确定”仅提示“按表格迁移功能暂未开发”，不调用 EB，也不保存操作日志。

### Excel 契约

沿用 `Templates/迁移模板图形模板.xlsx`：

| 列 | 内容 | 用途 |
| --- | --- | --- |
| A | 序号 | 预览显示，不参与匹配 |
| B | 模板图形目录 | 源目录相对路径 |
| C | 模板图形名称 | 在源目录中匹配模板图形 |
| D | 目标目录 | 目标目录相对路径 |

- 支持 `.xlsx` 和 `.xls`。
- 第一行为标题，从第二行开始读取。
- B、C、D 列全部为空的行忽略。
- 目录路径是图形模板根目录下的相对路径，不包含根目录“图形模版”。
- 路径使用 `/` 分隔；匹配时去除各路径段首尾空白。

### 缓存匹配与校验

导入预览只读取当前图形模板缓存，不重新读取 EB。

每行校验：

- 源目录不能为空。
- 模板图形名称不能为空。
- 目标目录不能为空。
- 源目录必须在缓存中唯一匹配，并且是最后一级目录。
- 目标目录必须在缓存中唯一匹配，并且是最后一级目录。
- 在源目录中按名称匹配模板图形，允许模板图形重名。
- 匹配数量必须恰好为 1；匹配为 0 或大于 1 时显示对应错误，不静默选择对象。

预览显示：

- Excel 行号
- 序号
- 源目录
- 模板图形名称
- 目标目录
- 源模板匹配数量
- 校验结果

## 新建模板图形

### 入口条件

- 在“图形模板”窗口工具栏新增“新建模板图形”按钮。
- 按钮在窗口忙碌时禁用，其他时候可点击。
- 点击后校验：
  - 已选择左侧目录。
  - 所选目录是最后一级目录。
  - 所选目录中恰好存在一个模板图形。
- 条件不满足时提示：

  `需要选择最后一级目录，并且目录中只能存在一个模板图形。`

### 数量输入

满足入口条件时弹出输入窗口：

- 用户输入最终总数量 `n`，包括目录中原有的模板图形。
- 只能输入正整数。
- 范围为 `2-200`。
- 输入无效时禁用“确定”按钮并显示校验提示。

### EB 操作

主程序向 adapter 发送：

- 当前目录 ID
- 当前目录中唯一模板图形的 ID
- 最终总数量 `n`

adapter 执行：

1. 确认目标目录和源模板仍然存在。
2. 确认源模板仍位于目标目录中。
3. 确认目录中仍恰好存在一个模板图形。
4. 对源模板执行一次 `aucCmdSymCopy`。
5. 对当前目录连续执行 `n-1` 次 `aucCmdSymPaste`。
6. 每次粘贴后重新枚举当前目录，通过新增对象 ID 读回确认本次创建结果。
7. 若出现“图形符号类型与图形模板类型不匹配”确认框，继续使用现有白名单 Win32 自动点击“确定”逻辑。
8. 任一次粘贴或读回失败后立即停止，不再执行后续复制。
9. 保留此前已经成功创建的模板图形，不回滚、不删除。

### 结果与日志

操作完成后：

- 刷新当前目录并更新该部分缓存。
- 打开结果窗口。
- 结果窗口显示请求总数量、原有数量、成功创建数量、最终确认数量和失败信息。
- 保存 JSON 和 TXT 日志。
- 提供“打开日志目录”按钮。

结果状态：

- `completed`：成功创建 `n-1` 个模板图形。
- `partial`：创建了部分模板图形后失败。
- `failed`：未创建任何模板图形。

## 架构

- 主程序继续通过 `EbAdapterClient` 与 adapter 进行 JSON 标准输入/输出通信。
- EB COM 复制、粘贴和读回逻辑只放在 `Adapters/AdapterProgram.cs`。
- 主程序和 adapter 两侧同步新增请求、响应和记录模型。
- 表格导入、路径匹配、数量校验和结果状态计算使用独立的可测试类。
- 不修改现有“迁移模板图形”的复制语义和日志语义。

## 失败策略

- 表格导入或预览失败：清空预览并显示错误，不调用 EB。
- 新建操作预校验失败：不执行复制，返回失败结果。
- 新建操作中途失败：立即停止，保留此前成功对象，展示结果并记录日志。
- 未识别的 EB 对话框不自动点击。

- 测试相对路径标准化和缓存目录匹配。
- 测试源目录、目标目录末级校验。
- 测试模板名称匹配数量为 0、1、多个的结果。
- 测试数量 `2-200` 边界及无效输入。
- 测试新建结果 `completed`、`partial`、`failed` 状态计算。
- 运行全部测试和主程序构建。
- 编译 EB 2023/2024 adapter。
