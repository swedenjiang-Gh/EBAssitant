# “工作表”批量创建功能设计

## 1. 目标与范围

在 EBAssistant 主界面增加可用的“工作表”功能。功能连接当前活动 EB，展示并缓存数据库 `/ 项目模板` 下的目录和模板项目。用户在模板项目上右键选择“新建工作表”，通过 Excel 批量创建器件工作表，并将其保存到所选模板项目的 `/ 工作表 / 收藏`。

首版不展示模板项目内部的“工作表”“收藏”节点，也不展示已有工作表。

## 2. 已确认技术路线

采用强类型 EB COM 公共 API 与现有版本适配器架构。

创建工作表、添加属性列、设置列标签、自动调整列宽、读回和删除能力，在开发实施阶段使用当前 EB 和临时工作表统一进行一次受控验证。验证通过后，正式功能不再在每批创建前执行临时能力验证，也不重复执行列宽读回验证。

如果开发阶段发现某项 API 不可用，先调查正确公共 API；不启用未验证或可能留下残留对象的正式写入路径。

## 3. 项目模板树

### 3.1 数据来源

- 根入口：`Application.Folders.ProjectTemplates`。
- 树中显示项目模板目录和模板项目对象。
- 保持 EB 中的原始层级和原始顺序。
- 不显示模板项目内部的“工作表”“收藏”节点及已有工作表。
- 目录树打开后默认全部折叠。

### 3.2 缓存

- 首次读取完整项目模板树后持久化缓存。
- 缓存按“EB 版本 + 项目模板根目录 ID”隔离，避免不同数据库误用。
- 后续打开“工作表”窗口时，先读取轻量身份信息，再优先展示缓存。
- 只有用户点击“刷新”时，才重新遍历 EB 并覆盖缓存。
- 创建工作表不会改变项目模板目录树，因此创建完成后不刷新目录树或缓存。

### 3.3 交互

- “工作表”窗口为独立非模态窗口。
- 窗口提供“刷新”按钮。
- 只有模板项目对象允许右键“新建工作表”。
- 项目模板目录节点不能执行“新建工作表”。

## 4. 新建工作表窗口

窗口显示所选模板项目路径，并提供：

- “导入表格”按钮。
- “确定”按钮。
- 只读预览表格。

所有新建工作表的对象类型固定为“器件”，界面不提供对象类型选择。

## 5. Excel 格式

- 支持 `.xlsx` 和 `.xls`。
- Excel 中每个页签对应一个待创建的 EB 工作表。
- Excel 页签名称作为 EB 工作表的原始名称。
- 每个页签的第一列固定忽略，仅作为备注或说明列。
- 从第二列开始，每一列对应 EB 工作表中的一列。
- 第一行是工作表中显示的列标签。
- 第二行是该列绑定的属性 ID。
- 第三行及以后全部忽略。
- 保持 Excel 页签顺序和页签内列顺序。

## 6. 导入预览与校验

导入后显示完整预览，包括：

- Excel 页签名称。
- 最终工作表名称。
- 保存目标模板项目。
- 对象类型“器件”。
- 列顺序。
- 列标签。
- 属性 ID。
- 自动列宽状态。
- 页签校验结果及错误原因。

### 6.1 名称规则

- 工作表名称去除首尾空格。
- 如果 `/ 工作表 / 收藏` 中已存在同名工作表，自动使用当前可用的最小序号：
  - `名称`
  - `名称 (2)`
  - `名称 (3)`
- 批次内名称冲突也使用相同规则计算最终名称。

### 6.2 页签级校验

出现以下任一情况时，将整个 Excel 页签标记为无效并跳过：

- 页签名称为空或无效。
- 没有任何可创建的列。
- 列标签为空。
- 属性 ID 不是正整数。
- 属性 ID 在当前 EB 中不存在。
- 同一页签内存在重复属性 ID。

无效页签不阻止其他有效页签创建。预览中明确显示错误，最终日志记录错误页签、错误列和原因。

## 7. EB 写入流程

适配器提供以下内部操作：

- `GetProjectTemplateIdentity`
  - 返回 EB 版本、项目模板根目录 ID 和名称。
- `GetProjectTemplateTree`
  - 返回项目模板目录和模板项目树。
- `ValidateWorksheetAttributeIds`
  - 校验 Excel 中使用的属性 ID。
- `CreateWorksheets`
  - 接收模板项目 ID、固定对象类型“器件”以及有效工作表和列配置。

正式创建流程：

1. 重新解析所选模板项目，并定位其 `/ 工作表 / 收藏`。
2. 读取已有工作表名称，计算每个有效页签的最终名称。
3. 按 Excel 页签顺序逐个创建工作表。
4. 将对象类型设置为“器件”。
5. 按 Excel 列顺序添加属性列。
6. 为每列设置 Excel 第一行提供的列标签。
7. 自动调整每列宽度，使列标签能够完整显示。
8. 记录最终保存路径：
   `项目模板 / 模板项目 / 工作表 / 收藏 / 最终工作表名称`
9. 单个工作表失败时记录失败，并继续创建其他有效工作表。
10. 创建完成后不重新读取项目模板目录树。

## 8. 开发阶段一次性能力验证

正式功能启用前，使用当前 EB 的受控临时工作表一次性验证：

1. 定位模板项目的 `/ 工作表 / 收藏`。
2. 创建器件工作表。
3. 按顺序添加多个属性列。
4. 设置自定义列标签，其中至少包含一个较长标签。
5. 自动调整列宽，使列标签完整显示。
6. 读回确认工作表名称、属性 ID、列顺序、列标签和列宽。
7. 删除临时工作表。
8. 确认临时工作表无残留。

一次性验证通过后，正式批量创建流程不再执行临时能力验证，也不重复读回验证列宽。

## 9. 自动列宽

- 每个正式工作表完成属性列和标签配置后执行自动列宽。
- 目标是使每个列标签完整显示。
- 自动列宽功能在开发阶段单独完成一次受控验证。
- 正式功能中不重复验证列宽结果。
- 若正式执行时自动列宽失败，将对应工作表记录为创建失败，并继续处理其他工作表。

## 10. 结果与日志

每次用户点击“确定”后，无论成功、部分成功或全部失败，都自动保存：

- JSON 结构化日志。
- TXT 可读日志。
- 日志目录：`%LOCALAPPDATA%\EBAssistant\Logs\Worksheets`。

操作完成后弹出“工作表创建结果”窗口，显示：

- Excel 页签名称。
- 最终工作表名称。
- 保存完整路径。
- 对象类型“器件”。
- 属性列数量。
- 自动列宽执行结果。
- 状态：创建成功、创建失败、校验失败跳过、未处理。
- 失败或跳过原因。

结果窗口提供“打开日志目录”按钮。

日志写入失败不会改变已经完成的 EB 创建结果，但必须明确提示日志保存失败。

## 11. 异常处理

- Excel 文件无法读取：停止导入并提示，不执行创建。
- 单个页签校验失败：跳过该页签，继续其他有效页签。
- 单个工作表创建、列配置或自动列宽失败：记录失败，继续其他工作表。
- EB 连接中断或所选模板项目不存在：停止后续工作表，并将剩余工作表记录为未处理。
- 不因工作表创建结果刷新项目模板目录树。

## 12. 测试计划

- 验证 EB2023、EB2024 当前活动实例连接。
- 验证项目模板目录和模板项目完整读取、原始顺序和默认折叠。
- 验证首次读取生成缓存、后续缓存秒开、刷新覆盖缓存，以及不同数据库缓存隔离。
- 验证右键菜单只允许模板项目执行“新建工作表”。
- 验证 `.xlsx`、`.xls`、多页签、第一列忽略、第三行以后忽略。
- 验证页签名称、列标签、属性 ID、不存在属性 ID和页签内重复属性 ID。
- 验证同名工作表使用最小可用序号。
- 开发阶段一次性验证创建、列顺序、列标签、自动列宽、读回与删除清理。
- 验证单个工作表失败后继续其他工作表。
- 验证结果窗口、JSON 日志和 TXT 日志内容一致。
- 完整构建主程序和版本适配器，检查新增文本文件为 UTF-8 无 BOM。

## 13. 首版不包含

- 不显示 `/ 工作表 / 收藏` 节点和已有工作表。
- 不创建、重命名或删除项目模板目录。
- 不允许用户选择器件以外的对象类型。
- 不提供工作表打开、导出、编辑或删除功能。
- 正式批量创建时不执行临时能力验证。
