# 权限配置首版只读结构设计

## 目标

实现“权限配置”功能的首版界面，只读取并展示后续权限配置所需的两个对象范围：

- 左侧递归展示数据库确定目录“用户及用户组”下的结构。
- 右侧展示数据库一级目录，供后续选择权限控制目标。

本轮不读取具体权限、不修改权限，也不实现右侧目录展开。

## 已确认范围

### 左侧：用户及用户组

- 数据根节点固定使用 `Application.Folders.UsersAndGroups`。
- 从根节点的 `Children` 开始递归读取完整结构。
- 界面显示“用户及用户组”根节点，便于一次勾选整棵结构。
- 不额外读取 `Application.AccessControl`、Windows 用户、EB 用户组或组成员关系。
- 使用带复选框的 `TreeView` 展示。
- 加载完成后默认全部折叠。
- 勾选父节点时，递归勾选全部子节点。
- 取消任一子节点时，重新计算并取消不再满足全选条件的父节点。
- 勾选状态仅用于后续权限配置，本轮不触发任何 EB 操作。

### 右侧：权限控制目录

- 读取数据库一级目录，不递归读取子目录。
- 数据库一级目录通过 `Application.RootObject.Children` 枚举。
- 排除“信息”和“用户及用户组”两个不需要设置权限控制的目录。
- 排除时使用确定目录对象的 ID 比较，不依赖界面语言下的目录名称。
- 选中目录后，右键菜单提供“展开”。
- 本轮点击“展开”仅提示“将在后续开发中实现”，不读取子目录。

## 界面设计

新增非模态窗口 `PermissionConfigurationForm`，由主界面“权限配置”入口打开。

窗口主体使用左右分栏：

- 左侧标题为“用户及用户组”，主体为带复选框的目录树。
- 右侧标题为“权限控制目录”，主体为数据库一级目录树。
- 顶部提供“刷新”按钮。
- 顶部提供“打开日志目录”按钮。
- 底部状态栏展示连接、缓存加载、重新读取和失败信息。

窗口连接活动 EB 的方式与属性、工作表窗口一致：

- 未检测到活动 EB 时，提示用户先打开 EB 并连接数据库。
- 多个 EB 版本同时活动时，让用户选择目标 EB。

## 数据模型与适配器协议

新增两个只读适配器操作：

- `GetPermissionConfigurationIdentity`：读取数据库根目录、“用户及用户组”和“信息”的对象身份，供缓存隔离和右侧排除使用。
- `GetPermissionConfigurationStructure`：读取左侧完整结构和右侧数据库一级目录。

返回结构包含：

- EB 版本。
- 数据库根目录的 ID 和名称。
- “用户及用户组”根目录的 ID 和名称。
- 左侧递归节点：ID、名称、完整路径、对象 Kind、子节点。
- 右侧一级目录节点：ID、名称、完整路径、对象 Kind。

主程序 `Models.cs` 与适配器 `Adapters/AdapterProgram.cs` 底部的 `[DataContract]` 模型必须同步修改。

适配器只允许读取以下对象：

- `Application.Folders.UsersAndGroups`
- `Application.Folders.Messages`
- `Application.RootObject.Children`
- 上述对象的 `ID`、`Name`、`Kind` 和 `Children`

适配器不得调用 `Store()`、`SetRight`、创建、删除或其他修改数据库状态的 API。

## 缓存

左右结构作为同一次读取结果共同缓存。

缓存键使用：

- EB 版本
- 数据库根目录 ID

首次打开窗口时：

1. 连接活动 EB。
2. 获取数据库根目录身份。
3. 若存在协议版本一致的缓存，直接展示缓存。
4. 无可用缓存时，从 EB 读取并保存缓存。

仅用户点击“刷新”时重新读取 EB 并覆盖缓存。修改树结构协议时提升缓存协议版本。

## 错误处理

- 无活动 EB：提示用户先打开 EB 并连接数据库，不启动新的 EB。
- 无法取得数据库根目录：停止加载并显示适配器错误。
- 无法取得“用户及用户组”目录：停止加载并显示适配器错误。
- 单个子节点读取失败：整个读取操作失败，不缓存不完整结构。
- 右侧无法取得“信息”目录身份：整个读取操作失败，避免误把该目录列为可配置目标。
- 缓存解析失败或协议版本不一致：忽略缓存并重新读取 EB。

## 结果与日志

每次初始加载或点击“刷新”完成后：

- 状态栏展示数据来源、左侧节点数、右侧目录数和结果状态。
- 保存 JSON 和文本日志，记录 EB 版本、数据库根目录身份、数据来源、节点数量、排除目录身份和错误信息。
- 日志保存到 `%LOCALAPPDATA%\EBAssistant\Logs\PermissionConfiguration`。
- “打开日志目录”按钮打开上述目录。

日志只记录读取结果，不记录或触发任何权限修改。

## 测试与验证

自动测试覆盖：

- 缓存按 EB 版本和数据库根目录 ID 隔离。
- 缓存协议版本不一致时不加载。
- 右侧目录按对象 ID 排除“信息”和“用户及用户组”。
- 左侧节点模型能保留递归结构。

构建验证：

- `dotnet build .\EBAssistant.csproj`
- `dotnet run --project .\Tests\EBAssistant.Tests.csproj`
- 使用 Visual Studio MSBuild 构建 EB 2023/2024 适配器。

真实 EB 验证：

1. 打开“权限配置”窗口，确认左右结构来自当前数据库。
2. 确认左侧默认折叠并显示复选框。
3. 验证父子复选框联动。
4. 确认右侧不显示“信息”和“用户及用户组”。
5. 点击右侧“展开”，确认只显示后续实现提示。
6. 确认状态栏展示结果，并可通过按钮打开日志目录。
7. 关闭并重新打开窗口，确认优先从缓存加载。
8. 点击“刷新”，确认重新读取并更新缓存。

## 不在本轮范围

- 读取或展示任何具体权限。
- 使用 `Application.AccessControl`。
- 对用户、用户组或目录执行新增、修改、删除。
- 保存左侧勾选状态。
- 展开右侧目录。
- 应用或撤销权限配置。
