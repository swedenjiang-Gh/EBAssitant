# 图形模板迁移记录

## 2026-06-14 跨大类复制边界

当前图形模板功能已改为复制粘贴语义：复制模板图形到目标目录，源对象保留。

已观察到的边界：

- 同类型或相近目录之间，`aucCmdSymCopy` + `aucCmdSymPaste` 可创建目标目录下的新模板图形，并能读回确认。
- 跨大类目录复制，例如从 `图形模板 / 器件` 复制到 `图形模板 / 功能`，在 EB 操作层面不允许或不稳定。
- 该场景可能提示“图形符号类型与图形模板类型不匹配。单击‘确定’转换图形符号类型”，但当前复制命令返回后，目标目录未必创建可读回的模板图形。

后续验证假设：

- 需要单独验证底层是否存在可控路径，能够保留模板图形的符号内容，同时将模板图形类型转换为目标目录允许存放的类型。
- 在找到可读回、可追踪、可清理的底层路径前，不把跨大类复制视为已支持能力。
